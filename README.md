## Alertas predictivas para correa overland

[Ver el proyecto](overland-predictivo/README.md) · [Descargar paquete completo](overland-predictivo/proyecto_overland.zip)

Incluye código, datos, notebook, modelo entrenado e informes. Datos sintéticos; la evaluación no demuestra superioridad global frente al warning de 16.
